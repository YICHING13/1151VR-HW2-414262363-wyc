一、遊戲介紹
這次使用 Unity 製作一款 2D 平台跳躍遊戲，以奶油塊作為主角，玩家需要控制奶油在廚房場景中的平台間移動，最後碰到吐司就算過關。
操作方式：
  左右方向鍵：移動
  上方向鍵：普通跳躍
  Space：強力跳躍
  下方向鍵：加速下降

二、遊戲製作
首先建立背景、角色、平台及終點，並利用 Rigidbody2D 和 Collider2D 設定角色的重力與碰撞。
角色移動使用 Vector2 控制水平及垂直速度，跳躍則使用 Array 儲存兩種不同的力量，讓玩家可以依照平台距離選擇跳躍高度。
另外加入掉落重生機制，讓奶油掉出畫面後能回到起點。碰到吐司後則會顯示過關畫面，並停止角色移動。

三、額外優化
1. 移動慣性
原本奶油按下方向鍵就會立即移動，放開後也會直接停止，操作起來比較生硬。
因此加入加速與減速機制，使用 Mathf.MoveTowards() 讓速度逐漸變化，使奶油移動時更加滑順。
2. 呼吸動畫
原本奶油只有靜態圖片，為了讓角色更有動感，另外製作了 Idle、Run、Jump 三種伸縮效果。
使用 Mathf.Sin() 製作待機時的呼吸動畫，並透過 Vector3.Lerp() 讓不同動畫之間的切換更加自然。
3. 粒子特效
另外也使用 Unity 的 Particle System 加入粒子效果，讓遊戲畫面不會只有靜態的背景和平台。
透過調整粒子的大小、速度及持續時間，增加場景的動態感，讓整體視覺效果更豐富。

四、遇到的問題
製作過程中主要遇到角色碰撞判斷、掉落後的位置設定，以及過關後角色仍會繼續移動等問題。
後來透過 isGrounded 判斷是否落地、記錄初始位置處理重生，並加入 isGameOver 和   FreezeAll，讓角色過關後停止移動。
另外在加入動畫時，曾出現奶油突然變形的情況，後來透過平滑縮放改善。

五、完成結果與改進方向
最後完成了基本的平台跳躍與過關功能，也實際運用到 Vector2 和 Array。
除了基本要求之外，另外加入移動慣性與呼吸動畫，讓角色的操作與畫面表現更加自然。
不過目前的平台設計還是比較單調，未來可以考慮將平台改成餅乾、吐司等符合廚房主題的造型，讓整體畫面更有一致性。
另外也可以增加重新開始功能，讓玩家過關後不需要重新啟動遊戲就能再次挑戰。
